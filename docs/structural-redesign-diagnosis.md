# Structural redesign diagnosis

The earlier interface used a permanent admin-style sidebar, a summary rail, a uniform card grid, repeated league metadata and tiny uppercase labels. Scores competed with containers and navigation instead of carrying the experience.

Plan: retain Next.js routes/domain/state and working controls; move desktop navigation into the top bar; retain mobile bottom navigation; remove both sidebars; build one cohesive vertical scores feed, with one leading simulated-live matchup and quieter divided score rows; use larger team identities and tabular numbers; integrate date/filter controls; make game previews a scoreboard stage with a separate compact quarter section. Replace uppercase micro-labels with plain supporting text. Retain disclosure and honest preview scope.
